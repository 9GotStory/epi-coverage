# การแสดงข้อมูลรายบุคคลจาก HDC

หน้ารายชื่อเด็กอายุ 1, 2, 3 และ 5 ปีมี 2 มุมมองตามตัวชี้วัด: มุมมองที่ 1 (รายชนิดวัคซีน) ใช้รายการกลางแยกตามกลุ่มอายุร่วมกับกฎรายปี ส่วนมุมมองที่ 2 (Fully Immunized) คือ “รายชื่อและประวัติจาก HDC” ตามรายละเอียดด้านล่าง แท็บ OpenData แสดงข้อมูลรวมแยกต่างหาก

- ผลในรายชื่อแสดงค่า `result` ที่โหลดมาโดยตรง ไม่มีการคำนวณผ่าน/ไม่ผ่าน เติมคำว่า “ขาด” หรือสร้างสถานะรอรับบริการ
- ตัวกรองผลใช้ค่าที่พบจริงใน `result` และค้นหารายชื่อได้ด้วยชื่อ CID หรือ PID
- ปีงบประมาณและไตรมาสยังกรองช่วงวันเกิดตามกลุ่มอายุเดิม
- ประวัติมุมมองที่ 2 แสดงทุกคอลัมน์ที่ลงท้าย `_date` ใน record หนึ่งคอลัมน์ต่อหนึ่งแถว รวมคอลัมน์ที่มีค่าว่าง แสดงชื่อคอลัมน์ต้นทางใต้ชื่อวัคซีน
- วันที่ในประวัติแสดง DD-MM-YYYY ตามส่วนวันที่จาก API เช่น `2023-10-03T17:00:00.000Z` → `03-10-2023` ไม่เลื่อนเขตเวลาและไม่แก้ข้อมูลหรือคอลัมน์วันที่ต้นทางใน export ไม่รวม LAJE/JE หรือ Rota เป็นรายการเดียว
- ข้อสังเกตวันที่แสดงเฉพาะในประวัติการรับวัคซีน ไม่แสดงเป็นคอลัมน์ในตารางหรือไฟล์ส่งออกรายชื่อ และไม่ต่อท้ายคำว่า “ขาด”
- ตั้งค่าการตรวจวันเกิด คู่เข็มห้ามวันซ้ำ และลำดับวันที่ได้จาก Vaccine Rules Engine ใช้กับทั้งสองมุมมอง โดยไม่เปลี่ยน `result` ของ HDC ส่วนผลประเมินรายชนิดใช้กฎวันที่ที่กำหนด
- ค่าเริ่มต้นเปรียบเทียบภายในชุดเดียวกัน แยก Rota 2/3 เข็มและ LAJE/JE ผู้ดูแลเลือกคู่ต่างชนิดเพิ่มเติมได้เอง ข้อสังเกตเป็นการตรวจข้อมูล ไม่ใช่ข้อห้ามฉีดร่วมกันทางการแพทย์
- มุมมองที่ 1 แสดงเฉพาะวัคซีนในกลุ่มอายุ รวมถึงประวัติและ Excel โดยรักษา date_checks รายปี รายการไม่พอประเมินแยกจากขาดวัคซีน รายละเอียดและ mapping ที่ยังต้องยืนยันดู [HDC column upgrade](hdc-column-upgrade.md)
- รหัสสถานบริการที่ฉีดมาจาก `_hospcode` และหน่วยบันทึกมาจาก `_input_hosp` แสดงแยกกัน พร้อมที่อยู่และประเภทพื้นที่
- เซลล์ null/ว่างแสดง “—” ส่วนฟิลด์ที่ไม่มีหลักฐานต้นทางแสดง “ไฟล์ไม่มีคอลัมน์ / ยังไม่มีข้อมูลต้นทาง” ไม่แปลว่าไม่ได้รับวัคซีน
- ไม่แสดงหรือเรียกใช้ AI วิเคราะห์ในหน้าประวัติ
- Excel ส่งออกรายชื่อที่กรองแล้ว พร้อมคอลัมน์วันที่และรหัสสถานบริการของวัคซีนแยกกัน PDF ส่งออกเฉพาะรายชื่อและผลต้นทางตามชื่อปุ่ม

ข้อมูลนี้เป็นข้อมูล HDC **ที่นำเข้าและโหลดจาก API** ไม่ใช่การดึงจาก HDC สด และไม่ใช่สำเนาเซลล์ Excel ก่อนผ่านขั้นตอน normalize วันที่ในการนำเข้า

การแสดงผล HDC นี้ครอบคลุมรายชื่อและการส่งออกในมุมมองที่ 2 ทั้งสี่กลุ่มอายุ และหน้าประวัติที่ใช้ร่วมกันกับมุมมองที่ 1 ส่วน Executive Summary, Year Comparison, การสร้าง summary ตอนอัปโหลด ของ View 2 และตัวจัดการกฎของแอดมินยังใช้ระบบเดิม ส่วน summary View 1 ใช้รายการกลางตามอายุแล้ว จึงไม่ควรนำตัวเลขสรุปเดิมมาอธิบายว่าเป็นการนับ `result` โดยตรง

# การแสดงข้อมูลรายบุคคลจาก HDC

หน้ารายชื่อเด็กอายุ 1, 2, 3 และ 5 ปีใช้มุมมองเดียวคือ “รายชื่อและประวัติจาก HDC” แทนมุมมองรายชนิดและ Fully Immunized เดิม ส่วนแท็บ OpenData ยังคงแสดงข้อมูลรวมแยกต่างหาก

- ผลในรายชื่อแสดงค่า `result` ที่โหลดมาโดยตรง ไม่มีการคำนวณผ่าน/ไม่ผ่าน เติมคำว่า “ขาด” หรือสร้างสถานะรอรับบริการ
- ตัวกรองผลใช้ค่าที่พบจริงใน `result` และค้นหารายชื่อได้ด้วยชื่อ CID หรือ PID
- ปีงบประมาณและไตรมาสยังกรองช่วงวันเกิดตามกลุ่มอายุเดิม
- ประวัติแสดงทุกคอลัมน์ที่ลงท้าย `_date` ใน record หนึ่งคอลัมน์ต่อหนึ่งแถว รวมคอลัมน์ที่มีค่าว่าง แสดงชื่อคอลัมน์ต้นทางใต้ชื่อวัคซีน
- วันที่คงค่าที่ API ส่งมา ไม่ตัดสินวันที่ก่อนวันเกิดหรือวันที่ซ้ำ และไม่รวม LAJE/JE หรือ Rota เป็นรายการเดียว
- รหัสสถานบริการที่ฉีดมาจากคอลัมน์ `_hospcode` คู่กับวันที่ ถ้ามี
- ค่า null, undefined และข้อความว่างแสดง “—” ไม่แปลว่าไม่ได้รับวัคซีน
- ไม่แสดงหรือเรียกใช้ AI วิเคราะห์ในหน้าประวัติ
- Excel ส่งออกรายชื่อที่กรองแล้ว พร้อมคอลัมน์วันที่และรหัสสถานบริการของวัคซีนแยกกัน PDF ส่งออกเฉพาะรายชื่อและผลต้นทางตามชื่อปุ่ม

ข้อมูลนี้เป็นข้อมูล HDC **ที่นำเข้าและโหลดจาก API** ไม่ใช่การดึงจาก HDC สด และไม่ใช่สำเนาเซลล์ Excel ก่อนผ่านขั้นตอน normalize วันที่ในการนำเข้า

การเปลี่ยนแปลงนี้ครอบคลุมหน้ารายชื่อ ประวัติ และการส่งออกทั้งสี่กลุ่มอายุ ส่วน Executive Summary, Year Comparison, การสร้าง summary ตอนอัปโหลด และตัวจัดการกฎของแอดมินยังใช้ระบบเดิม จึงไม่ควรนำตัวเลขสรุปเดิมมาอธิบายว่าเป็นการนับ `result` โดยตรง

ตรวจสอบด้วย `npm run build` และ `./node_modules/.bin/vitest run src/shared/utils/vaccine/hdcData.test.ts` จากโฟลเดอร์ `frontend`
